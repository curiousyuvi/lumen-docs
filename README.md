# Lumen Docs

A small stand-in knowledge base app used to evaluate documentation tools. It has a password login, a dashboard, a Knowledge Hub with publish and unpublish, Customize tabs (General, Theme & Styling, Domains & Redirects, SEO), Billing, Members and Analytics, plus a dark mode toggle.

Run with `npm start`. Set `DEMO_USER` and `DEMO_PASS` to change the login. State lives in memory and resets on restart.
